# 01. RFID & Inventory Technology

## Overview

RFID 기술을 활용하여 서가의 도서를 자동으로 인식하고
장서 상태 및 배열 상태를 점검하는 기술을 정리합니다.

## Library Applications

- 장서점검
- 오배가 도서 탐지
- 분실도서 탐지
- 자료 위치 확인
- 서가 상태 점검
- 장서관리 자동화

## Core Technologies

- RFID Tag
- RFID Reader
- RFID Antenna
- Mobile RFID Reader
- Autonomous Robot
- Library Management System Integration

## Research Questions

- 이동형 로봇의 RFID 인식 정확도는 어느 정도인가?
- 서가의 높이와 RFID 인식률은 어떤 관계가 있는가?
- 다단 서가를 어떻게 효율적으로 스캔할 수 있는가?
- 장서관리시스템과 로봇을 어떻게 연동할 수 있는가?
