# 07. Integrated Robot Systems

## Overview

도서관 업무를 수행하기 위해 여러 로봇 기술을
통합하는 시스템 구조를 정리합니다.

## Example: Autonomous Library Shelving Robot

### Step 1. Book Recognition

Computer Vision과 OCR을 이용하여 책과 청구기호를 인식

### Step 2. Location Identification

도서관 장서정보와 청구기호를 이용하여 배가 위치 판단

### Step 3. Autonomous Navigation

SLAM과 LiDAR를 이용하여 해당 서가까지 이동

### Step 4. Book Manipulation

Robot Arm과 Gripper를 이용하여 책을 파지

### Step 5. Shelving

정확한 서가 위치에 도서를 배가

### Step 6. Verification

RFID 또는 Computer Vision을 이용하여 배가 결과 확인
