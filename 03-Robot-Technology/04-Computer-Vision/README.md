# 04. Computer Vision

## Overview

카메라와 AI를 이용하여 도서, 청구기호, 서가 및
도서관 환경을 인식하는 기술을 정리합니다.

## Library Applications

- 책등 인식
- 청구기호 인식
- 오배가 탐지
- 서가 위치 인식
- 장애물 인식
- 이용자 인식

## Core Technologies

- Object Detection
- OCR
- Image Recognition
- Deep Learning
- Depth Camera
- 3D Vision

## Library-Specific Challenges

- 작은 청구기호 라벨
- 다양한 책등 디자인
- 조명 및 그림자
- 밀집된 도서
- 유사한 서가 구조
- 가려진 라벨
