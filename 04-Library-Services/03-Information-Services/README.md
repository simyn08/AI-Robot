# 03. Information Services

## Overview

AI와 로봇을 활용한 참고정보서비스, 정보검색 및
연구지원 서비스의 적용 가능성을 정리합니다.

## Library Tasks

- 참고정보서비스
- 정보검색 지원
- 자료검색
- 연구지원
- 학술정보 안내
- 이용자 질의응답

## AI Applications

| AI Application | 한국어 | 도서관 AI 로봇에서의 활용 |
|---|---|---|
| **AI Chatbot** | AI 챗봇 | 이용자의 질문을 이해하고 도서 검색, 시설 안내, 이용시간, 대출·반납 등 반복적인 문의에 자동으로 응답 |
| **Large Language Model (LLM)** | 대규모 언어 모델 | 자연어를 이해하고 생성하여 이용자와의 대화, 질문 응답, 정보 탐색 및 맞춤형 안내를 지원 |
| **Retrieval-Augmented Generation (RAG)** | 검색증강생성 | 도서관 소장자료, 이용안내, 학술정보 등 신뢰할 수 있는 내부 정보를 검색한 후 생성형 AI가 이를 바탕으로 답변하도록 지원 |
| **Recommendation System** | 추천 시스템 | 이용자의 관심 분야, 검색·대출 정보 및 자료 특성을 분석하여 도서와 학술정보 등 맞춤형 콘텐츠를 추천 |
| **AI Agent** | AI 에이전트 | 이용자의 요청이나 목표를 이해하고 필요한 정보를 탐색·판단·계획하여 여러 단계의 도서관 서비스를 자율적으로 수행 |

## Robot Applications

AI 기반 정보서비스를 로봇 인터페이스와 결합하여
도서관 내에서 이용자에게 대화형 정보서비스를 제공할 수 있습니다.

## Example Service Flow

이용자 질문
→ AI 질의 분석
→ 도서관 데이터 검색
→ 관련 자료 추천
→ 소장 위치 확인
→ 로봇의 서가 위치 안내
