# 03. Information Services

## Overview

AI와 로봇을 활용한 참고정보서비스, 정보검색 및
연구지원 서비스의 적용 가능성을 정리합니다.

## Library Tasks

- 참고정보서비스
- 정보검색 지원
- 자료검색
- 연구지원
- 학술정보 안내
- 이용자 질의응답

## AI Applications

- AI Chatbot
- Large Language Model
- Retrieval-Augmented Generation (RAG)
- Recommendation System
- AI Agent

## Robot Applications

AI 기반 정보서비스를 로봇 인터페이스와 결합하여
도서관 내에서 이용자에게 대화형 정보서비스를 제공할 수 있습니다.

## Example Service Flow

이용자 질문
→ AI 질의 분석
→ 도서관 데이터 검색
→ 관련 자료 추천
→ 소장 위치 확인
→ 로봇의 서가 위치 안내
