# 02. Information Organization

## Overview

도서관 자료의 분류, 목록, 메타데이터 구축 및
데이터 품질관리 업무에서 AI 기술의 활용 가능성을 정리합니다.

## Library Tasks

- 자료 분류 지원
- 목록 작성 지원
- 주제어 및 키워드 생성
- 메타데이터 자동 생성
- 데이터 오류 탐지
- 데이터 품질관리
- 청구기호 인식

## AI Applications

이 영역은 물리적 로봇보다는 AI Agent 및
생성형 AI와의 연계 가능성이 높은 분야입니다.

## Connection with Physical AI

자료조직 데이터는 Physical AI 로봇의 장서관리 업무와 연결될 수 있습니다.

예:

청구기호 데이터
→ 도서 위치 판단
→ 자율주행
→ 도서 탐색
→ 자동 배가
