# 05. Reading & Cultural Services

## Overview

AI 로봇을 활용한 독서지원 및 도서관 문화프로그램
서비스의 적용 가능성을 정리합니다.

## Library Tasks

- 맞춤형 도서추천
- 독서상담
- 독서프로그램 안내
- 문화행사 안내
- 동화구연
- 어린이 독서활동
- 교육프로그램 지원

## Robot Applications

### Personalized Recommendation

이용자의 관심 분야와 독서이력을 기반으로
맞춤형 도서를 추천합니다.

### Reading Assistant

이용자와 대화하며 독서 관련 질문에 응답하고
책에 대한 정보를 제공합니다.

### Storytelling Robot

어린이 이용자를 대상으로 동화구연 및
상호작용형 독서활동을 지원합니다.

### Program Assistant

독서 및 문화프로그램을 안내하고
프로그램 운영을 지원합니다.
