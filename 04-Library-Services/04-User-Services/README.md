# 04. User Services

## Overview

도서관 이용자와 직접 접촉하는 서비스에
AI 로봇을 적용할 수 있는 분야를 정리합니다.

## Library Tasks

- 도서관 시설 안내
- 길찾기
- 자료 위치 안내
- 이용자 질문 응대
- 대출·반납 안내
- 좌석 및 시설 안내
- 프로그램 안내
- 다국어 안내

## Robot Functions

- Autonomous Navigation
- Voice Interaction
- Touch Screen
- Natural Language Processing
- Multilingual Service
- Location Guidance

## Related Robot Cases

- 큐아이(QI)
- 마중이
- Pepper

## Research Perspective

안내 로봇은 현재 도서관에서 비교적 많이 적용된
서비스 로봇 유형으로, 향후 생성형 AI와 결합하여
단순 안내에서 지능형 정보서비스로 확장할 수 있습니다.
