# 04. User Services

## Overview

도서관 이용자와 직접 접촉하는 서비스에
AI 로봇을 적용할 수 있는 분야를 정리합니다.

## Library Tasks

- 도서관 시설 안내
- 길찾기
- 자료 위치 안내
- 이용자 질문 응대
- 대출·반납 안내
- 좌석 및 시설 안내
- 프로그램 안내
- 다국어 안내

## Robot Functions

| Function | 한국어 | 도서관 AI 로봇에서의 활용 |
|---|---|---|
| **Autonomous Navigation** | 자율주행 | 도서관 내부를 스스로 이동하며 이용자를 목적지까지 안내하고 서가·시설 등의 위치 안내를 지원 |
| **Voice Interaction** | 음성 상호작용 | 이용자의 음성 질문을 인식하고 도서 검색, 시설 이용, 대출·반납 등의 정보를 음성으로 안내 |
| **Touch Screen** | 터치스크린 | 이용자가 화면을 통해 자료를 검색하거나 서비스·시설 안내 메뉴를 직접 선택할 수 있도록 지원 |
| **Natural Language Processing (NLP)** | 자연어 처리 | 이용자의 질문과 요청을 자연어로 이해하고 적절한 정보와 답변을 제공 |
| **Multilingual Service** | 다국어 서비스 | 다양한 언어로 질문을 이해하고 정보를 제공하여 외국인 이용자의 도서관 이용을 지원 |
| **Location Guidance** | 위치 안내 | 검색한 도서의 서가 위치, 열람실 및 편의시설 등의 위치를 안내하고 필요시 목적지까지 동행 |

## Related Robot Cases

- 마중이
- Pepper

## Research Perspective

안내 로봇은 현재 도서관에서 비교적 많이 적용된
서비스 로봇 유형으로, 향후 생성형 AI와 결합하여
단순 안내에서 지능형 정보서비스로 확장할 수 있습니다.
