### Behind Singapore's Library System

- **Organization:** CNA (Channel NewsAsia)
- **Robot / Technology:** RFID, Automated Sorting, Shelf-Reading Robot
- **Summary:** 싱가포르 도서관의 RFID 기반 자료관리, 자동분류 및 장서점검 로봇 등 도서관 자동화 과정을 소개하는 영상
- **Research Relevance:** RFID 기반 장서관리와 로봇 자동화가 실제 도서관 업무 프로세스에 어떻게 적용되는지 확인할 수 있는 사례
- **URL:** https://www.channelnewsasia.com/watch/behind-singapores-library-system-5990631

### bookBot at Hunt Library

- **Organization:** NC State University Libraries
- **Library:** James B. Hunt Jr. Library
- **Robot / Technology:** bookBot / Automated Storage and Retrieval System (ASRS)
- **Summary:** 자동화된 크레인이 보관함을 찾아 자료를 검색·반출하는 bookBot의 실제 작동 과정을 보여주는 영상
- **Research Relevance:** 로봇 기반 자료 보존·검색과 도서관 공간 효율화 사례를 이해하는 데 활용
- **URL:** https://www.lib.ncsu.edu/videos/bookbot-hunt-library

### How the bookBot Works

- **Organization:** NC State University Libraries
- **Library:** James B. Hunt Jr. Library
- **Robot / Technology:** Automated Storage and Retrieval System (ASRS)
- **Summary:** 이용자의 자료 요청부터 자동화 시스템의 자료 검색 및 직원에게 전달되는 과정까지 bookBot의 작동 원리를 설명
- **Research Relevance:** 도서관 자동화 시스템에서 로봇과 사서의 업무가 어떻게 분담되는지 분석하는 데 활용
- **URL:** https://www.lib.ncsu.edu/videos/how-bookbot-works-nc-state-university-libraries

### AuRoSS / Robotic Library Inventory

- **Organization:** A*STAR / Singapore Library Projects
- **Robot / Technology:** AuRoSS, RFID, Autonomous Navigation
- **Summary:** 자율주행 로봇이 서가를 이동하면서 RFID 태그를 인식하여 장서를 점검하는 기술 사례
- **Research Relevance:** RFID 기반 장서점검, 오배가 탐지 및 자율주행 로봇의 도서관 적용 연구에 활용
- **URL:** 관련 공식 영상 및 프로젝트 자료 추가 예정

### Autonomous Library Shelving Robot

- **Organization:** National University of Singapore (NUS) / NUS Libraries
- **Robot / Technology:** AMR, Robot Arm, Computer Vision, Call Number Recognition
- **Summary:** 청구기호를 인식하고 배가 위치를 판단한 후 자율주행과 로봇팔을 이용하여 도서를 서가에 배가하는 연구 프로젝트
- **Research Relevance:** 장서점검을 넘어 도서 인식·이동·파지·배가까지 수행하는 Physical AI 기반 도서관 로봇 연구에 활용
- **URL:** https://cde.nus.edu.sg/edic/projects/urop-ay2026/
