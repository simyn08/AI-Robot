# 03. Library Robot Projects

도서관 장서관리, 자동배가, 운반, 안내 등과 관련된
AI 로봇 연구 및 개발 프로젝트를 추적합니다.

## Autonomous Library Shelving

### NUS Autonomous Library Shelving Robot

National University of Singapore와 NUS Libraries의
자율형 도서 배가 로봇 연구 프로젝트

Main Technologies:

- Autonomous Mobile Robot (AMR)
- Robot Arm
- Computer Vision
- Call Number Recognition
- Autonomous Navigation
- Robotic Shelving

Research Relevance:

도서의 청구기호를 인식하고 배가 위치를 판단한 후,
자율주행 로봇과 로봇팔을 이용하여 실제 서가에
도서를 배가하는 통합형 도서관 로봇 연구 사례

Website:
https://cde.nus.edu.sg/edic/projects/urop-ay2026/

## Library Inventory Robots

### AuRoSS

RFID와 자율주행 기술을 활용한 도서관 장서점검 로봇 연구

Research Topics:

- RFID Inventory
- Autonomous Navigation
- Shelf Scanning
- Library Automation

Research Topics:
